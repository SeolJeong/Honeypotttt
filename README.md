# HoneyAI

Evasion-aware attribution of SSH attack sessions: is the actor a **human**, a **script**, or an **AI agent** - even when the AI is deliberately imitating a human?

ICT3214 Security Analytics - Coursework 2 (group project).

## How to run

All scripts are run from the project root (`Honeypotttt/`).

### 1. Feature extraction

Regenerates `dataset2_tabular_features.csv` from `dataset1_sessions.json`:

```
python scripts/extract_features.py
```

### 2. Stage-1 auth-noise filter

Trains and evaluates the brute-force login filter on `dataset3_auth_noise.csv`:

```
python -m honeyai.stage1_filter
```

### 3. Train XGBoost (Model 1)

Trains on dataset2, reports CV and held-out test metrics:

```
python scripts/train_xgboost.py
```

Expected output: CV macro-F1 ~0.964, test macro-F1 ~0.691.

### 4. Train GRU (Model 2)

Trains on dataset1 sequences, reports CV and multi-seed test metrics:

```
python scripts/train_gru.py
```

Expected output: CV macro-F1 ~0.919, test macro-F1 ~0.713.

### 5. Train QLoRA LLM (Model 3)

Requires a CUDA GPU (RTX 4050 or better, or Google Colab T4).

Local GPU:
```
python scripts/train_qlora_local.py
```

Saves predictions to `data/qlora_predictions.json`.

### 6. Evasion experiments

Runs all three experiments (per-evasion breakdown, evasive vs non-evasive, commands-only ablation). Requires XGBoost and GRU to be trained inline. Loads QLoRA predictions from `data/qlora_predictions.json`.

```
python scripts/run_evasion_experiments.py
```

### 7. Dashboard

Launches an interactive Streamlit dashboard with four tabs: model comparison, evasion analysis, session inspector, and wild data classifier.

```
streamlit run honeyai/dashboard.py
```

### 8. Parse Cowrie logs

Converts raw Cowrie JSON logs into HoneyAI session format:

```
python scripts/parse_cowrie.py external/cowrie/cowrie.json
```

Parse and classify with trained XGBoost:

```
python scripts/parse_cowrie.py external/cowrie/cowrie.json --classify
```

Output is saved to `data/wild_sessions.json`.

## Dataset details

### v2b dataset (canonical, in `data/`)

- **2,312 sessions** (1,482 train / 830 test)
- Three actor classes: human (800), scripted (636), AI-driven (876)
- Each session runs on a randomised fake Linux host
- Human timing calibrated to KYPO real cybersecurity trainees
- 7 script families with genuine control flow
- 3 AI agent families with 6 evasion strategies
- Group-disjoint splits: unseen personas, families, and evasion strategies at test time

### Splits discipline

| Dimension | Train | Test (held out) |
|---|---|---|
| Human personas | SP01-SP12 | SP13-SP20 |
| Script families | 4 families | 3 families |
| AI agent families | sim_agent_a, sim_agent_b | sim_agent_c |
| Evasion strategies | 5 strategies | avoid_systematic_enumeration, combined |

### Features (19 numeric, extracted by `features.py`)

| Category | Features | Description |
|---|---|---|
| Timing (6) | session_duration_s, inter_cmd_mean/std_s, min/max_gap_s | Speed and variability |
| Command (3) | cmd_len_mean/std, unique_cmd_ratio | Complexity and diversity |
| Error (4) | typo_count/rate, error_count/rate | Dead-end responses (excludes hints) |
| Adaptation (3) | not_found_with_hint_count, adaptation_event_count, error_recovery_rate | Hint-following behaviour |
| Sequence (3) | final_task_progress, interaction_depth, sequence_entropy | Progress and diversity |


## Key results

### Overall performance

| Model | CV macro-F1 | Test macro-F1 |
|---|---|---|
| XGBoost | 0.964 | 0.691 |
| GRU | 0.919 | 0.713 |
| QLoRA LM | - | 0.724 |

### Evasion robustness (AI-driven recall)

| Strategy | XGBoost | GRU | QLoRA |
|---|---|---|---|
| none | 0.875 | 0.938 | 0.938 |
| timing_mimicry | 0.938 | 0.969 | 0.875 |
| shorter_commands | 0.812 | 0.188 | 0.875 |
| combined (all) | 0.287 | 0.312 | 0.287 |

Combined evasion reduces AI detection from ~90% to ~29% across all models.

### Wild data (live Cowrie honeypot)

12 interactive sessions extracted from 13,315 events. Predicted: 9 scripted, 2 human, 1 AI-driven.


## File descriptions

### `honeyai/` (core package)

| File | Purpose |
|---|---|
| `responses.py` | Simulates realistic Linux shell output for 28+ programs on a consistent fake host. Replaces placeholder responses in the dataset. |
| `features.py` | Extracts 19 numeric features from dataset1 sessions. Every formula reverse-verified against the team's canonical CSV. |
| `stage1_filter.py` | Logistic regression on 3 auth features. Separates brute-force noise from interactive sessions. |
| `cowrie_parser.py` | Parses raw Cowrie JSON logs into dataset1 format. Handles session grouping, idle splitting, typo detection. |
| `dashboard.py` | Streamlit app with 4 tabs: model comparison, evasion analysis, session inspector, wild data upload. |
| `models/xgb_baseline.py` | XGBoost with grouped CV (StratifiedGroupKFold), class weights, feature importance ranking. |
| `models/gru_sequence.py` | GRU with per-step encoding (token embeddings + timing + response category), multi-seed evaluation. |
| `models/qlora_lm.py` | Shared utilities for QLoRA: prompt formatting, JSON prediction parsing, results loading. |
| `experiments/evasion_analysis.py` | Three experiments: per-strategy breakdown, evasive vs non-evasive recall, commands-only ablation. |

### `scripts/` (entry points)

| File | What it runs |
|---|---|
| `fix_responses.py` | Applies realistic responses to dataset1, regenerates dataset4 |
| `extract_features.py` | Runs `features.py`, outputs dataset2 |
| `train_xgboost.py` | Trains and evaluates XGBoost |
| `train_gru.py` | Trains and evaluates GRU |
| `train_qlora_local.py` | Trains QLoRA on local GPU (3 seeds) |
| `run_evasion_experiments.py` | Runs all evasion experiments |
| `run_dashboard.py` | Launches Streamlit dashboard |
| `parse_cowrie.py` | Parses raw Cowrie logs, optional classification |


## Data collection

A live Cowrie SSH honeypot collects real attacker traffic as unlabelled wild data. This is used for distribution comparison, case studies, and the demo only - never for training or reported accuracy.

KYPO data (external/kypo/) is from: V. Svabensky et al., "Dataset of shell commands used by participants of hands-on cybersecurity training," Data in Brief, vol. 38, 2021. CC BY 4.0. Used for timing calibration only.
